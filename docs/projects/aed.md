
# AED Box (`aed-box`)

`aed-box` is a monitoring and readiness platform for Automated External Defibrillators (AEDs), designed to reduce risk and improve response confidence.

---

## Overview

The goal is simple: keep every AED visible, auditable, and ready for emergency use.

`aed-box` tracks device presence, readiness state, and service intervals so teams can act before a unit becomes unavailable.

---

## Key Accomplishments

- Built a monitoring workflow that continuously reports AED state and last-known status.
- Added maintenance-oriented alerts for battery/pad checks and service windows.
- Created a clear tracking model so teams can identify location and readiness issues quickly.
- Structured event history for compliance-style audit trails and operational accountability.
- Reduced manual spreadsheet-style tracking by centralizing status into a single system view.

---

## What I Delivered

- Device status collection and heartbeat reporting
- Alerting hooks for maintenance and exception events
- Operational dashboard data model for fleet-level visibility
- Reliable data flow from edge unit to server for reporting and follow-up
